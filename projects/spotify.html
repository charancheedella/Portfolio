The idea

A clone of Spotify's web player, designed purely with HTML and CSS. It recreates the layout, style and feel of the real interface in its dark theme. It's built for desktop and large screens.

What it does

  • A left sidebar with navigation and library sections.
  • A top bar with search and the premium prompt.
  • Trending, curated and personalised playlist cards.
  • A fully designed player bar with controls.
  • A dark theme true to the original.
  • A layout tuned for desktop and large screens.

Built with

  • HTML5
  • CSS3
  • Flexbox
  • Media queries
  • Google Fonts
  • Font Awesome

What I learned

  • Building complex layouts with Flexbox.
  • Dark theme styling and separating sections clearly.
  • Media queries for basic responsiveness.
  • Organising assets and code cleanly in a UI project.
