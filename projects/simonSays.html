The idea

A memory game built with HTML, CSS and JavaScript. The game flashes a sequence of colours and you repeat it. Every correct round adds one more colour, so it tests your focus a little more each time.

What it does

  • A start button to begin and restart.
  • A sequence that grows by one each round.
  • Interactive colour pads with smooth animations.
  • Level and high score tracking.
  • A simple, responsive layout.

Built with

  • HTML5
  • CSS3
  • JavaScript

What I learned

  • Writing game logic in JavaScript.
  • Handling user events and validating the sequence.
  • Structuring code cleanly for a small web game.
